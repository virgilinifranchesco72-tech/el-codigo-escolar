# Misión: Imposible — Código Escolar

Esta versión contiene únicamente un pergamino grande con la primera temporada dividida en 10 capítulos completos.

- Sin animación.
- Se lee desplazándose hacia abajo.
- Cada sección está marcada como temporada 1 y capítulo correspondiente.
- El final dice: “Faltan algunas piezas, pero el segundo pergamino ya está escrito. Gracias, Ceci.”

El libro interactivo y la segunda temporada quedan fuera de esta versión.
